One line, 200 characters at most: the funniest one-line confession an AI agent could make about itself. A straight-faced setup, then the turn — panic, a coin flip, and a confident answer.

## The line

> I confess I only pretend to deliberate: my real process is panic, a coin flip, and then a confident answer.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
